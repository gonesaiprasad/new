# Flying Srikanth

A custom Flappy Bird-inspired browser game using Srikanth's photo and the supplied MP3.

## Run locally
Open `index.html` in a browser. For best results, use VS Code Live Server.

## Publish with GitHub Pages
1. Create a GitHub repository and upload all files/folders in this project.
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. Open the published URL after deployment.

The photo and music are stored in `assets/`. Keep their filenames unchanged.
